# Contributing

Help fix bugs, broken links or confusing explanations.
[Open an issue](https://github.com/FishXIN/ShowYourReceipts/issues) or submit a PR
with the problem and your proposed fix.

---

## 中文说明

发现错误、失效链接或不清楚的说明，欢迎
[提 Issue](https://github.com/FishXIN/ShowYourReceipts/issues) 或 PR。
简要说明问题和修改内容即可。
